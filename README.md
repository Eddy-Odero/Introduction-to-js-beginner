# Piscine JS

A collection of **JavaScript exercises inspired by the Piscine methodology**, designed to help learners practice problem-solving, JavaScript fundamentals, and writing clean, testable code.

The project includes:

* 🧩 Exercises for learners to solve
* 🧪 Automated tests to check solutions
* ✅ Reference solutions for comparison
* 📚 Progressive challenges from beginner to more advanced topics

##  Getting Started

### 1. Clone the repository

```bash
git clone <repository-url>
cd piscine-js
```

### 2. Install dependencies

```bash
npm install
```

### 3. Choose an exercise

Navigate to the exercise you want to work on:

```bash
cd exercises/exercise-01
```

Read the exercise instructions and implement your solution.

## Solving Exercises

Each exercise contains instructions describing what you need to implement.

For example:

```text
exercise-01/
├── quiz.txt.md
└── solution.js
```

Your task is to implement the required function in `solution.js`.

Try to solve the exercise **without looking at the reference solution first**.

## Solutions

Reference solutions are included for learning purposes.

You can find them in:

```text
solutions/
```

For example:

```text
solutions/
├── exercise-01.js
├── exercise-02.js
└── exercise-03.js
```

### Recommended workflow

1. Read the exercise.
2. Try to solve it yourself.
3. Run the tests.
4. Debug your implementation.
5. Only after attempting the problem, compare your solution with the reference solution.
6. Understand **why** the reference solution works rather than simply copying it.

> The goal is to learn JavaScript and problem-solving, not just to make the tests pass.

## Tests

Tests are intentionally designed to check different cases, including:

* Normal inputs
* Edge cases
* Empty values
* Invalid inputs where applicable
* Multiple inputs
* Expected return values

Passing the visible tests does not necessarily mean an implementation is optimal. Learners are encouraged to think about readability, correctness, and edge cases.

##  Learning Goals

By completing the exercises, you should become more comfortable with:

* Writing JavaScript from scratch
* Breaking problems into smaller steps
* Understanding JavaScript's core concepts
* Debugging code
* Writing functions that are easy to test
* Reading and understanding test cases
* Thinking about edge cases
* Comparing different implementations

## About the Solutions

The solutions are provided as **reference implementations**.

They are not necessarily the only correct solutions. JavaScript problems can often be solved in multiple ways.

If your solution passes all the tests and follows the requirements, it may be completely valid even if it looks different from the reference solution.
