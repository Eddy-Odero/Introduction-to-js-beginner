In this project, you will recreate the functionality of .filter(), .map(), and .reduce() — but instead of working with arrays, you’ll apply them to object values. This exercise deepens your understanding of how to iterate over and transform objects using higher-order functions, preparing you for more complex data manipulation tasks in JavaScript.

Role Play
You’re planning your grocery list and want to analyze the nutritional values of your ingredients. Each food item is an object representing nutrients per 100 grams. To make your analysis efficient, you’ll build three helper functions — filterValues, mapValues, and reduceValues — that let you filter, transform, and aggregate nutrition data with the same flexibility as array methods.

Learning Objective
By completing this project, you will learn how to:

Apply functional programming principles to JavaScript objects.

Use callbacks to filter, transform, and aggregate data.

Work with Object.entries() and Object.fromEntries() to manipulate key-value pairs.

Understand the logic behind filter, map, and reduce methods at a deeper level.

Instructions
General
Create three functions that behave like the .filter(), .map(), and .reduce() array methods, but operate on an object’s values instead.

filterValues
Filters the object’s values based on a callback function.

const nutrients = { carbohydrates: 12, protein: 20, fat: 5 };

filterValues(nutrients, (nutrient) => nutrient <= 12);
// → { carbohydrates: 12, fat: 5 }
mapValues
Transforms each value in the object according to a callback function.

const nutrients = { carbohydrates: 12, protein: 20, fat: 5 };

mapValues(nutrients, (v) => v + 1);
// → { carbohydrates: 13, protein: 21, fat: 6 }
reduceValues
Aggregates all values in the object into a single result using a callback function.

const nutrients = { carbohydrates: 12, protein: 20, fat: 5 };

reduceValues(nutrients, (acc, cr) => acc + cr);
// → 37
