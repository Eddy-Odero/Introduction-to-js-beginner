In this project, you will recreate the functionality of .filter(), .map(), and .reduce(), but this time operating on the keys of an object instead of its values. This task will help you strengthen your understanding of object manipulation, functional programming, and how to dynamically transform or aggregate object structures in JavaScript.

Role Play
You’re shopping for groceries, but your preferences have changed — no onions, more oranges! To efficiently manage your grocery data, you decide to create three custom functions — filterKeys, mapKeys, and reduceKeys — that allow you to filter, transform, and aggregate the keys of your grocery cart object with the same power and flexibility as array methods.

Learning Objective
By completing this project, you will learn how to:

Iterate over object keys and apply callback-based logic.

Implement key-based versions of filter, map, and reduce.

Manipulate object structures dynamically while preserving values.

Use Object.entries() and Object.fromEntries() effectively for transformations.

Instructions
General
Create three functions that replicate the behavior of the array methods .filter(), .map(), and .reduce(), but operating on the keys of an object.

filterKeys
Filters the keys of an object based on a callback condition.

const nutrients = { carbohydrates: 12, protein: 20, fat: 5 };

filterKeys(nutrients, (key) => /protein/.test(key));
// → { protein: 20 }
mapKeys
Transforms each key in the object according to a callback function.

const nutrients = { carbohydrates: 12, protein: 20, fat: 5 };

mapKeys(nutrients, (k) => `-${k}`);
// → { -carbohydrates: 12, -protein: 20, -fat: 5 }
reduceKeys
Aggregates all keys into a single result using a callback function.

const nutrients = { carbohydrates: 12, protein: 20, fat: 5 };

reduceKeys(nutrients, (acc, cr) => acc.concat(", ", cr));
// → "carbohydrates, protein, fat"
