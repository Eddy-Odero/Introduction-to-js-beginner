In this project, you will implement functional utilities that operate on the entries of an object — pairs of [key, value] elements. You’ll recreate .filter(), .map(), and .reduce() methods for object entries, then use them to build higher-level functions that analyze and transform nutritional data from a grocery cart.

Role Play
You’re optimizing your grocery tracking system. Each item in your cart has nutritional data, and you need tools to filter, transform, and summarize this data efficiently. By working directly with object entries, you’ll build powerful functions that help you calculate totals, find low-carb foods, and aggregate nutritional facts across your groceries.

Learning Objective
By completing this project, you will learn how to:

Work directly with object entries ([key, value] pairs).

Implement .filter(), .map(), and .reduce() behavior for objects.

Combine lower-level utilities to create data analysis functions.

Perform computations and filtering using functional programming techniques.

Instructions
General
Create three functions that replicate array methods for object entries:

filterEntries

mapEntries

reduceEntries

Each function will receive both the key and value of an entry, represented as a [key, value] array.

filterEntries
Filters object entries based on a condition involving the key and/or value.

filterEntries(object, ([k, v]) => condition);
mapEntries
Transforms entries by modifying the key, the value, or both.

mapEntries(object, ([k, v]) => [newKey, newValue]);
reduceEntries
Aggregates all entries into a single value using a callback function.

reduceEntries(object, (acc, [k, v]) => newAcc);
Derived Functions
Create three additional functions that use your previous implementations and take an object as input:

totalCalories
Returns the total number of calories in the cart.

lowCarbs
Returns a filtered cart containing only items with less than 50 grams of carbs after total calculation.

cartTotal
Returns an object representing the complete nutritional breakdown of each item in the grocery cart — including calories, protein, carbs, sugar, fiber, and fat.

Watch out for floating-point precision. Each nutritional value is per100gValue * grams / 100, but doing that division per value leaves tiny binary-floating-point artifacts (e.g. 61.87200000000001 instead of 61.872), and the tests compare with exact equality. Round each computed value to 3 decimal places (e.g. Math.round(x * 1000) / 1000), and for totalCalories sum value * grams first and divide by 100 once at the end, so the results land on the exact expected numbers.

Think carefully about the structure of Object.entries() — each entry is [key, value], and you can rebuild objects using Object.fromEntries().

Usage
Below is an example script to test your functions:

The value for each item in groceriesCart is the number of grams.

const groceriesCart = { orange: 500, oil: 20, sugar: 480 };

console.log("Total calories:");
console.log(totalCalories(groceriesCart));
console.log("Items with low carbs:");
console.log(lowCarbs(groceriesCart));
console.log("Total cart nutritional facts:");
console.log(cartTotal(groceriesCart));
