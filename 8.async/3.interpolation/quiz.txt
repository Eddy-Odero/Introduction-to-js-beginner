In this project, you will create a function that performs linear interpolation between two points over time. By dividing a total duration into evenly spaced intervals, the function will gradually move from a starting value to an ending value, invoking a callback at each step to simulate animation or timed progression.

Role Play
You are building an animation engine that smoothly transitions an object from one position to another. To achieve this, you’ll design a function called interpolation() that computes incremental values between a start and an end point, executing a callback function at each step over a specified duration.

Learning Objective
By completing this project, you will learn how to:

Perform linear interpolation between two values.

Use timing functions like setTimeout to control execution over time.

Calculate step sizes and interval durations dynamically.

Manage asynchronous operations in sequential loops.

Instructions
General
Create a function named interpolation that takes an object as its only argument, containing the following properties:

step: the number of interpolation points (excluding the end point).

start: the starting value.

end: the ending value.

callback: a function to execute at each interpolation point.

duration: the total time in milliseconds for the interpolation.

For each interpolation point i (from 0 up to step - 1), the function must call the callback with an array [value, time] where:

value is the interpolated position between start and end: start + (end - start) * (i / step).

time is the elapsed time at that point: duration * ((i + 1) / step).

Each callback fires duration / step milliseconds after the previous one (the first fires after one such interval, not synchronously).

So the array is [interpolated-value, elapsed-time], the second element is a time, not a second spatial value.

The interpolation should not include the final end value in the callback sequence (that is why i stops at step - 1).

For example, interpolation({ step: 5, start: 0, end: 1, duration: 10, callback }) calls: [0, 2] → [0.2, 4] → [0.4, 6] → [0.6, 8] → [0.8, 10].

Example
interpolation({
  step: 5,
  start: 0,
  end: 1,
  duration: 10,
  callback: (point) => console.log(point),
});
